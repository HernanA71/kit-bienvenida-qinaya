Documentación de API

Estructuras de datos requeridas para el Dashboard Analítico de Qinaya

Este documento detalla la estructura JSON exacta que la aplicación frontend (Dashboard) espera recibir por parte de la API de Qinaya para renderizar todas las gráficas y tablas. Se requieren 4 endpoints principales.

Nota para el desarrollador: Una vez expuestos estos endpoints, se debe actualizar la variable API_BASE_URL en el archivo dashboard.js (línea 24).

1. Lista de Clientes y Colegios /organizations

Propósito: Alimenta el filtro principal (Secretaría, Fundaciones, etc.) y los sub-filtros de sedes/colegios.

Estructura esperada (Array de objetos JSON):

[
  {
    "id": "sec-edu-bogota",
    "name": "Secretaría de Educación de Bogotá",
    "isPrimary": true,
    "sites": [
      "Colegio Virginia Gutiérrez",
      "Colegio El Salitre",
      "Colegio Los Comuneros"
    ]
  },
  {
    "id": "comfandi",
    "name": "Comfandi",
    "sites": ["Sede Palmira", "Sede Yumbo"]
  }
]

2. Histórico de Uso /usage

Propósito: Alimenta la gráfica principal de horas de uso local vs VDI a lo largo del tiempo.

Parámetros enviados (GET): ?org={id_cliente}&days={dias}&site={nombre_sede}

Estructura esperada: Un objeto con 4 arreglos (arrays) paralelos, de igual longitud.

{
  "labels": ["lun, 24 jun", "mar, 25 jun", "mié, 26 jun", "jue, 27 jun"],
  "localUsage": [1.5, 2.0, 1.2, 3.1],
  "vmUsage": [3.5, 4.2, 3.8, 5.0],
  "totalUsage": [5.0, 6.2, 5.0, 8.1]
}

3. Detalle de Equipos /computers

Propósito: Llena la tabla de detalle inferior y la gráfica de dona (Virtual vs Local) calculando sumatorias.

Parámetros enviados (GET): ?org={id_cliente}&site={nombre_sede}

Estructura esperada (Array de objetos):

[
  {
    "id": "QPC-001",
    "site": "Colegio Virginia Gutiérrez",
    "status": "online",
    "localHours": 4.5,
    "vmHours": 6.2,
    "totalHours": 10.7,
    "topApp": "Google Docs"
  },
  {
    "id": "QPC-002",
    "site": "Colegio Virginia Gutiérrez",
    "status": "offline",
    "localHours": 0.5,
    "vmHours": 1.2,
    "totalHours": 1.7,
    "topApp": "Scratch"
  }
]

4. Sitios Web Más Visitados /websites

Propósito: Llena la gráfica de barras horizontales categorizadas.

Parámetros enviados (GET): ?org={id_cliente}&site={nombre_sede}

Estructura esperada (Array ordenado por visitas):

[
  { "name": "youtube.com", "visits": 3200, "category": "General" },
  { "name": "docs.google.com", "visits": 1950, "category": "Productividad" },
  { "name": "colombiaaprende.edu.co", "visits": 1100, "category": "Educación" },
  { "name": "tinkercad.com", "visits": 800, "category": "Educación" }
]
